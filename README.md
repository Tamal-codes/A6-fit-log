# 🏋️‍♂️ FITLOG — Workout & Fitness Tracker

FitLog is a modern, responsive single-page web application designed to help users discover workouts, build custom daily training routines, and track their daily fitness progress seamlessly without page reloads.

---

## 🚀 Key Features

- **🧭 Dynamic Navbar with Live Counters:** Real-time badge indicators on the navigation bar that immediately reflect the total count of planned and saved workouts without reloading.
- **🏋️ Interactive Workout Cards:** Dynamic exercise library where users can easily add workouts to "Today's Plan" or bookmark them into "Saved Plan".
- **🔔 Toast Notification System:** Instant user feedback and alert toasts every time a workout is added, saved, or removed from the plan.
- **📊 Unique Metrics per Exercise:** Each workout card displays tailored attributes including distinct duration (time), calorie estimates, and user ratings.
- **⚡ Automated Plan & Saved Tracker:** Intelligent automatic calculation that dynamically sums up the total exercises, active minutes, and burned calories based on items selected in Today's Plan or Saved Plan.
